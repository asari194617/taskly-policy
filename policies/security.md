# セキュリティポリシー

An official version is provided in Japanese. English is not available right now.

セキュリティポリシーは、Tasklyが、情報セキュリティに対する適切な管理を重要な課題として認識し、情報セキュリティを確保するために、情報セキュリティに関する基本方針を定めたものです。

## 情報セキュリティ管理体制

Tasklyは、保有するすべての情報資産の保護および適切な管理を行うため、依存関係を含めたサービス全体での情報セキュリティ管理状況の把握と、リスク分析に従った必要なセキュリティ対策を迅速に実施できる技術的体制を維持します。

## 情報セキュリティ対策の実施

Tasklyは、情報資産に係る、情報漏えい、不正アクセス、破壊、改ざんなどの事故を防止するため、ショルダーハッキングやSQLインジェクション攻撃など様々な情報セキュリティに関わるリスクを認識し、適切な情報セキュリティ組織体制の整備、関係者のリファレンスチェック、物理的対策、技術的対策、運用的対策、管理的・人的対策、および事故対応対策を実施した上で、必要に応じて権限最小の原則に基づく情報の機密性に応じたアクセス制限を行います。

特に、情報セキュリティが侵害される事象が発生した場合には、早期にその復旧、解決にあたり、高い信頼性および継続性を担保しながらサービスを提供します。

## 法令などの遵守

Tasklyは、関係法令やガイドラインなどの遵守に加え、Tasklyが定めた規定・ルールなどの遵守徹底に努め、適切な情報管理に努力してまいります。
